# Bài thực hành 6 – Zigbee

Mở **BTH06.md** để xem báo cáo chi tiết. Thư mục **images/** chứa 3 ảnh gốc đã chèn theo đường dẫn tương đối.

Giải nén toàn bộ, giữ nguyên cấu trúc thư mục. Có thể mở bằng VS Code rồi nhấn Ctrl+Shift+V; hoặc đưa BTH06.md và images lên cùng thư mục GitHub.

Báo cáo ghi rõ kết quả trên Zigbee2MQTT và hướng dẫn làm tiếp Wireshark/ZBOSS; chưa có capture để xác nhận các trường gói tin. Bài này không cần code ESP32. Đã thêm code Python nhận MQTT và YAML Home Assistant; xem mục 11 trong BTH06.md.
