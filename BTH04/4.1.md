# 4.1 · Mạng IoT gia đình trong Packet Tracer

[Mục lục nhóm](README.md) · [PDF](../pdf/BTH04_TVQ.pdf)

## Mục tiêu

Tạo ba mạng con, đăng ký thiết bị và điều khiển qua IoT Server.
## Chuẩn bị

Cisco Packet Tracer có thiết bị Home Router, router hai cổng, switch, Server-PT và thiết bị IoT.
## Tệp dùng trong bài

- [code/packet_tracer/router.txt](../code/packet_tracer/router.txt)
- [code/packet_tracer/addressing.csv](../code/packet_tracer/addressing.csv)

## Thao tác chi tiết

### 1. Kéo thiết bị và nối dây

Đặt TVQ-Home, TVQ-R1, Switch, TVQ-Server, PC và Fan/Lamp/Door/AC. Nối cổng Internet/WAN của Home Router tới R1 G0/0; R1 G0/1 tới switch; switch tới server. Dùng Automatically Choose Connection Type nếu chưa biết loại cáp.

### 2. Đặt địa chỉ ba mạng

Dùng addressing.csv: LAN 192.168.27.0/24; Home WAN 10.27.1.2/24 gateway 10.27.1.1; R1 G0/0=10.27.1.1, G0/1=10.27.2.1; server=10.27.2.10/24 gateway 10.27.2.1. Router interfaces phải no shutdown; thay tên cổng nếu model khác.

### 3. Cấu hình Wi-Fi

Home Router GUI: LAN IP 192.168.27.1, bật DHCP; WAN Static theo bảng. Đặt SSID TVQ-LAB, WPA2-Personal AES và mật khẩu lab ít nhất 8 ký tự. Tạo guest SSID TVQ-GUEST nếu model hỗ trợ; không suy ra guest được cách ly nếu chưa kiểm chứng.

### 4. Bật IoT Server và đăng ký

Server → Services → IoT bật On. Trên PC mở http://10.27.2.10, Sign Up một tài khoản. Dùng đúng tài khoản đó trên từng thiết bị: Config/Settings → IoT Server hoặc Remote Server → IP 10.27.2.10 → Connect. Menu khác theo loại thiết bị; đừng trộn tài khoản của hai ví dụ trong đề.

### 5. Ping từng chặng rồi điều khiển

PC dùng DHCP. Ping lần lượt 192.168.27.1 → 10.27.1.1 → 10.27.2.1 → 10.27.2.10. Ping có thể mất gói đầu do ARP. Sau đó đăng nhập web server, bật/tắt từng thiết bị và lưu project .pkt trên máy bạn.

## Kiểm tra trước khi kết luận

- [ ] Router hai cổng up/up.
- [ ] PC ping server và danh sách IoT có thiết bị.
- [ ] Chụp bảng IP và trạng thái trước/sau điều khiển.

## Giải thích và trả lời

**Ethernet ở tầng nào?**

Ethernet cung cấp cơ chế liên kết dữ liệu/tầng vật lý; IP định tuyến giữa mạng, TCP cung cấp kết nối tin cậy cho nhiều ứng dụng.

**Vì sao gateway phải cùng subnet?**

Host phải chuyển khung trực tiếp tới router cục bộ để gửi dữ liệu ra mạng khác.

## Khi gặp lỗi

- Ping gateway được nhưng server không: kiểm tra R1, gateway server và WAN Home.
- Thiết bị không hiện: SSID, IP và thông tin đăng ký server chưa đúng.
