# 4.2 · Đèn bật theo cảm biến chuyển động

[Mục lục nhóm](README.md) · [PDF](../pdf/BTH04_TVQ.pdf)

## Mục tiêu

Tạo điều kiện Motion=true để bật Lamp qua IoT Server.
## Chuẩn bị

Hoàn thành 4.1; thêm Motion Detector và Lamp hỗ trợ remote registration.
## Tệp dùng trong bài

- [code/packet_tracer/addressing.csv](../code/packet_tracer/addressing.csv)

## Thao tác chi tiết

### 1. Thêm cảm biến và đèn

Đặt tên TVQ-Motion và TVQ-Lamp. Trong Config → Wireless, chọn TVQ-LAB và khóa Wi-Fi của bạn. Nếu thiết bị thiếu module không dây, tắt nguồn rồi đổi module phù hợp ở tab Physical.

### 2. Đăng ký cùng một server

Vào phần Remote Server của cả hai, nhập 10.27.2.10 và cùng tài khoản đã tạo. Kiểm tra cả cảm biến/đèn có mặt trên web IoT Server trước khi tạo rule.

### 3. Tạo condition/action

Trong trang Conditions của server, tạo rule TVQ-Motion-On: nếu trạng thái motion của TVQ-Motion là true thì TVQ-Lamp On. Tên trường có thể Motion/On/State tùy model. Chọn đúng thiết bị và thuộc tính từ menu thực tế.

### 4. Kích hoạt và ghi kết quả

Dùng Alt + nhấp trái theo thao tác tương tác của model hoặc cơ chế tạo chuyển động mà bản PT cung cấp. Xem trạng thái motion đổi rồi đèn sáng. Tắt đèn thủ công để kiểm tra đường điều khiển. Có thể thêm rule motion=false → Off và ghi rõ đây là phần mở rộng.

## Kiểm tra trước khi kết luận

- [ ] Cảm biến đổi trạng thái trước khi đèn đổi.
- [ ] Điều khiển tay vẫn dùng được.

## Giải thích và trả lời

**Rule chạy ở đâu?**

Trong kịch bản này logic điều kiện do IoT Server mô phỏng thực hiện, không phải code Arduino.

## Khi gặp lỗi

- Motion đổi nhưng đèn không: kiểm tra rule active, đúng thiết bị và cùng server.
