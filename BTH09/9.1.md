# 9.1 · Cài NS-3 và mở NetAnim

[Mục lục nhóm](README.md) · [PDF](../pdf/BTH09_TVQ.pdf)

## Mục tiêu

Có môi trường Debian/Ubuntu chạy được hello-simulator và hiểu vị trí file mô phỏng.
## Chuẩn bị

Máy Linux hoặc máy ảo có dung lượng trống nhiều GB; bản hướng dẫn nhắm ns-3.43.
## Tệp dùng trong bài

- [code/ns3/install.sh](../code/ns3/install.sh)

![Sơ đồ các bước bài 9.1](../assets/steps/9.1.png)

## Thao tác chi tiết

### 1. Kiểm tra tài nguyên trước

Terminal: df -h, free -h, nproc. Máy ảo cần đĩa đủ cho source/build; nên dành khoảng 10 GB trở lên để làm thoải mái và kiểm tra cả ổ host chứa máy ảo. Không chạy build khi ổ chỉ còn vài chục MB.

### 2. Cài công cụ

Chạy bash code/ns3/install.sh trên Debian/Ubuntu bằng user thường. Script dùng sudo cho apt, tải tag ns-3.43 về ~/ns-3-tvq, configure rồi build -j 2. Nó không cài vào Home Assistant OS hoặc add-on terminal.

### 3. Xác nhận build

Chạy cd ~/ns-3-tvq rồi ./ns3 run hello-simulator. Thấy Hello Simulator mới coi bước cơ bản đạt. Nếu thiếu header CMake phải sửa dependency rồi configure lại, không chỉ bấm chạy nhiều lần.

### 4. Cài NetAnim

Nếu repo Debian/Ubuntu có gói: sudo apt install netanim, sau đó netanim. Hoặc lấy NetAnim từ nsnam và build theo README của phiên bản tương ứng. Trên server SSH không có display phải chạy GUI ở môi trường desktop/X11 phù hợp.

### 5. Nhận biết thư mục

scratch/ dành cho code riêng; examples/ ví dụ; src/ module. Đặt mô phỏng vào scratch, chạy từ gốc bằng ./ns3 run scratch/tvq-lte. Bài 10 sẽ sinh tệp XML cho FlowMonitor và NetAnim, hai định dạng đó không dùng thay nhau.

## Kiểm tra trước khi kết luận

- [ ] hello-simulator chạy được.
- [ ] NetAnim có cửa sổ GUI hoặc ghi rõ máy chưa có display.

## Giải thích và trả lời

**NS-3 có phải kéo thả như Packet Tracer?**

Không. Kịch bản được viết bằng C++/Python API tương ứng; NetAnim chủ yếu đọc tệp animation để xem lại mô phỏng.

## Khi gặp lỗi

- Chạy sudo ./ns3: dùng user thường cho build/run.
- Không cửa sổ GUI qua SSH: kiểm tra DISPLAY/desktop.
