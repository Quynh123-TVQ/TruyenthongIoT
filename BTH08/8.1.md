## Mục tiêu

Nạp firmware qua USB, đưa LED thành entity và cập nhật OTA.
## Chuẩn bị

Home Assistant OS/ESPHome Device Builder, Wemos D1 mini ESP8266. Có biến thể ESP32-S3 với LED ngoài GPIO4.

## Thao tác chi tiết

### 1. Mở Device Builder và tạo thiết bị

Trong HA cài ESPHome Device Builder nếu chưa có, Start rồi Open Web UI. New Device đặt tên tvq-wemos và chọn đúng ESP8266/d1_mini. Nếu bạn dùng ESP32-S3 thì dùng tệp tvq-esp32s3.yaml, không nạp firmware Wemos cho S3.

### 2. Điền cấu hình và secrets

Sao secrets.example.yaml thành secrets.yaml trong thư mục ESPHome, điền SSID/password, API key base64 32 byte và mật khẩu OTA/fallback. Thay placeholder API key bằng khóa sinh tại wizard hoặc python -c "import os,base64;print(base64.b64encode(os.urandom(32)).decode())".

### 3. Nạp lần đầu bằng USB

Cắm board vào máy thực sự chạy trình nạp. Install → chọn USB local nếu trình duyệt/môi trường hỗ trợ; nếu board ở PC khác máy HA, chọn Download/Manual rồi dùng ESPHome Web để nạp qua USB tại PC. Không chọn cổng USB của máy chủ HA khi board đang cắm ở laptop.

### 4. Thêm integration

Khi log đã có IP, vào Settings → Devices & Services, nhận ESPHome được phát hiện hoặc Add Integration → ESPHome → nhập IP, port 6053 và encryption key khi được hỏi. Nếu báo cùng MAC đã được cấu hình, cập nhật thiết bị hiện có thay vì cố tạo bản sao.

### 5. Thử LED và OTA

Mở entity TVQ LED, bật/tắt quan sát LED. Wemos LED GPIO2 active-low; biến thể S3 dùng LED ngoài GPIO4 qua 330 Ω xuống GND, không giả định chân RGB onboard. Thử đổi friendly_name hoặc cấu hình rồi Install Wirelessly khi board vẫn online.

## Kiểm tra trước khi kết luận

- [ ] Log có IP và API kết nối HA.
- [ ] Entity làm LED thật thay đổi.
- [ ] OTA thành công trên LAN.

## Giải thích và trả lời

**mDNS khác DNS?**

mDNS dùng multicast cục bộ, thường UDP 5353 và hậu tố .local; DNS thông thường hỏi máy chủ DNS.

**YAML → firmware → OTA?**

YAML là cấu hình đầu vào; ESPHome sinh/biên dịch firmware .bin; OTA truyền firmware đó qua mạng. API cho HA cập nhật và điều khiển thiết bị.

**OTA cần điều kiện mạng nào?**

Thiết bị đang chạy firmware có OTA và còn truy cập được từ máy nạp; đúng mật khẩu/phương thức, đủ nguồn/flash và không bị firewall/cách ly LAN chặn. Không cần dây USB cho mỗi lần cập nhật sau lần đầu đã nạp hợp lệ.

**Vì sao điều khiển có vẻ real-time?**

HA duy trì kết nối native API với ESPHome để truyền lệnh và cập nhật trạng thái liên tục, độ trễ phụ thuộc mạng/thiết bị. Đây không phải bảo đảm hard real-time.

**Tại sao dùng YAML?**

Cấu hình khai báo giúp ESPHome sinh code từ component, kiểm tra cấu trúc và tái sử dụng. YAML không trực tiếp chạy trên vi điều khiển như firmware.

## Khi gặp lỗi

- Không thấy integration: kiểm tra cùng LAN/mDNS, thử IP trực tiếp.
- API key lỗi: phải là base64 đúng 32 byte, không để placeholder.
