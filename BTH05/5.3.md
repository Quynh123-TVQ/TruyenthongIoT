## Mục tiêu

Bấm nút trên web, gửi lệnh qua Node.js và COM tới LED.
## Chuẩn bị

Hệ thống 5.1 hoặc 5.2; Node.js LTS hỗ trợ serialport 13; thư mục bluetooth_web.

## Thao tác chi tiết

### 1. Chuẩn bị đường truyền

Nạp hc05_led. Với module thật, pair HC-05 trên Windows và xác định cổng SPP outgoing. Với COM ảo, dùng đầu PC của cặp ở 5.2. Không chọn COM USB của Uno nếu muốn kiểm tra đường HC-05.

### 2. Cài và mở server

Terminal tại code/bluetooth_web: chạy npm install rồi npm start. Mở http://127.0.0.1:3085. Server chỉ lắng nghe loopback để thao tác trên PC đang cắm cổng.

### 3. Kết nối đúng cổng

Nhấn Quét cổng, chọn COM rồi Kết nối. Khi trạng thái đã mở Serial, các nút Bật/Tắt được kích hoạt. Baud backend là 9600, phải trùng data baud HC-05/COMPIM.

### 4. Điều khiển và kiểm tra ACK

Bật LED: web POST /led, backend gửi ON và newline; Arduino trả STATE ON. Log web phải hiển thị phản hồi thật; HTTP sent chỉ chứng minh đã gửi tới Serial, không tự khẳng định LED thực đã bật.

### 5. Ngắt và thử lỗi

Nhấn Ngắt; nút điều khiển bị khóa. Thử mở sai COM để thấy lỗi hiển thị. Chụp giao diện, LED và log STATE. Trình duyệt kết nối backend qua WebSocket, không yêu cầu quyền Web Bluetooth để tìm HC-05.

## Kiểm tra trước khi kết luận

- [ ] Nhận phản hồi STATE ON/OFF từ thiết bị.
- [ ] Ngắt cổng làm nút vô hiệu.

## Giải thích và trả lời

**Vì sao cần Node.js?**

Node mở cổng Serial SPP/COM; trình duyệt gọi HTTP và nhận WebSocket. HC-05 Classic không phải BLE GATT.

## Khi gặp lỗi

- npm install lỗi: kiểm tra Node hỗ trợ dependency, mạng và quyền driver.
- Web mở được nhưng COM lỗi: đóng Monitor, chọn outgoing COM đúng.
